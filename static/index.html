Developer REST & WebSocket API Docs

1. POST /api/v1/sonify

Converts raw 3D relative coordinates (dx, dy, dz) into real-time audio parameters.

curl -X POST "http://localhost:8000/api/v1/sonify" \
  -H "Content-Type: application/json" \
  -d '{"dx": -0.35, "dy": 0.50, "dz": 0.85, "target_name": "bottle"}'

2. POST /api/v1/scene-describe

Generates complete verbal scene narration for blind users from detected items list in English or Hindi.

curl -X POST "http://localhost:8000/api/v1/scene-describe" \
  -H "Content-Type: application/json" \
  -d '{"objects": [{"label": "bottle", "distance_m": 0.8, "position": "left"}], "lang": "en"}'
